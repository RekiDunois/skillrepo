# AGENTS.md

Treat this repository and all commit, branch, tag, issue, and PR metadata as public. Never add credentials, private or environment-specific data, or real local/deployment identifiers; use synthetic examples instead. Keep documentation and tests reproducible, do not stage unrelated files, and review `git status` plus `git diff --cached --check`, `git diff --cached --stat`, and `git diff --cached` before every commit. Every commit message must use a Conventional Commit prefix, such as `feat: add repository registration`, `fix: handle missing config`, `docs: clarify setup`, or `chore: update tooling`, and must remain technical and environment-neutral.

When multiple agents work in this repository, or when the user asks to create a branch, use a sibling `worktrees/` directory with one worktree and branch per agent or requested branch; never switch branches in another agent's worktree, and verify changes before removing one. Agents must not glob `$HOME` or scan the home directory; restrict searches to the repository or an explicitly requested path. Do not copy local configuration, logs, private notes, or deployment output into tracked files. If a value may be sensitive or identifying, replace it with a clearly synthetic placeholder or stop before committing. If sensitive or identifying data has already been committed, a later deletion commit is insufficient; stop and determine whether history rewriting and credential rotation are required before publishing or pushing further changes.
